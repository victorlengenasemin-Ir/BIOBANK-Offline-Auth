# BIOBANK-Offline-Auth
### Offline Biometric Authentication for Rural Banking in Gemena, DRC
**By Ir Victor LENGENASEMIN**

#### 🎯 Problem
In Gemena (Equateur, DRC), internet is unstable. Rural banks cannot authenticate clients offline, causing fraud and exclusion.

#### 💡 Solution
A secure offline-first system combining:
- **Face Recognition:** Face++ API with local fallback
- **Fingerprint:** Neurotechnology VeriFinger SDK
- **Offline Encryption:** AES-256 for local biometric templates
- **Sync Engine:** Auto-sync when internet returns

#### 🛠️ Tech Stack
- Python / Flutter
- SQLite (offline DB)
- Face++ / VeriFinger
- AES-256 Encryption

#### 🌍 Impact
Financial inclusion for unbanked populations in remote DRC areas.
Aligned with UN SDG 1, 8, 9.
